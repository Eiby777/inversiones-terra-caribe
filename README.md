# Inversiones Terra Caribe SRL

Sitio corporativo de regalos, canastas navideñas y productos de limpieza para empresas.

**Web:** https://eiby777.github.io/inversiones-terra-caribe/

## Desarrollo

Sitio estático sin dependencias de compilación.

```sh
python3 -m http.server 4317
```

- `index.html`: contenido y estructura.
- `styles.css`: diseño adaptable y regalo colgante animado.
- `app.js`: menú móvil, galería y preparación de consultas en WhatsApp.
- `assets/`: imágenes oficiales y fuentes locales.

## Publicación

GitHub Pages publica la rama `main`, desde la raíz del repositorio. Los cambios enviados a esta rama se publican automáticamente.

## Imagen de limpieza

`assets/limpieza-empresas.webp` es una imagen ilustrativa generada con IA de las categorías confirmadas: jabones, jabón líquido, cloro, desgrasante y fundas negras. Representa la categoría; no describe marcas, tamaños o envases exactos del inventario.
